The Inventory Management Report is an interactive Power BI dashboard designed to monitor and analyze inventory performance, stock levels, product movement, and warehouse operations. The report provides key insights into total inventory, available stock, low-stock products, sales, purchases, inventory value, and product-wise performance.

The project uses Power Query for data cleaning and transformation and DAX to create calculated measures and KPIs. Interactive visuals and slicers help users analyze inventory data based on product, category, warehouse, supplier, and time period.

Key Features:

📦 Total inventory and available stock analysis
📊 Product and category-wise inventory analysis
⚠️ Identification of low-stock and out-of-stock products
💰 Inventory value and stock valuation analysis
📈 Sales and purchase trends
🏭 Warehouse-wise stock analysis
🚚 Supplier-wise inventory analysis
🔄 Stock movement and product turnover analysis
📌 KPI cards and interactive slicers
